# Ecommerce Image Director Skill

提供素材生成需要的主图和详情图。

面向电商商品主图、详情图、直播间封面、社交电商广告图的 Codex skill。

## 能力范围

- 根据产品图、品牌信息、平台要求和目标人群生成电商视觉方案。
- 支持抖音电商、淘宝/天猫、京东、小红书、Amazon、Shopify 等平台的主图、详情页、轮播图、直播封面、广告图。
- 内置品类策略、平台规格、视觉风格库、趋势学习、生成流程、QA 和知识更新规范。
- 强调产品真实保留：品牌、包装形态、SKU、材质、颜色、实物纹理优先。

## 依赖说明

这个 skill 本身是电商视觉知识库和工作流，不依赖外部服务也可以使用。它可以帮助完成：

- 产品信息拆解
- 电商图片规划
- 主图/详情图结构设计
- 风格方向生成
- 生图提示词编写
- 图片 QA 和上架风险检查
- 批量图片实验复盘

如果要直接生成图片，需要额外具备一种可用的生图能力，例如：

- Codex 内置图片生成能力
- `gpt-image-2` skill 或同类图片生成工具
- 其他支持参考图生成/编辑的模型或平台

没有生图工具时，也可以把本 skill 产出的提示词复制到其他图片生成平台使用。

## 调用示例

典型需求：

```text
根据这些产品素材，调用 ecommerce-image-director skill，
为抖音电商生成 10 张不重复风格的商品主图和详情图。
```

更完整的需求示例：

```text
产品：老崔皇原味古法瓜子
平台：抖音电商
目标：生成商品主图和详情图，一共 10 张，每张风格不要重复
要求：尽量保留真实包装，突出透明袋、颗粒饱满、原香酥脆、开袋即食
输出：图片方案、生成提示词、图片 QA、备注文件
```

## 推荐工作流

1. 提供产品图、包装图、卖点、目标平台和目标人群。
2. 先让 skill 输出图片地图，确定每张图的用途和风格。
3. 再分批生成图片，每 1-3 张检查一次产品是否跑偏。
4. 对生成结果做 QA：产品真实度、文案可信度、手机端可读性、平台适配度。
5. 把有效风格和失败经验更新到知识库，方便下一次复用。

## 注意

- AI 生成图里的小字、条码、营养表、资质信息和功效类文案不能直接当最终上架信息。
- 工厂、产地、认证、排名、销量、价格、功效等声明需要真实资料验证。
- 正式上架建议进行后期文字排版，确保文案、字号、留白和平台审核更可控。

## 常见问题

### 这个 skill 可以直接出图吗？

skill 负责完整的电商视觉流程、提示词和 QA。是否能直接出图，取决于使用者本机或当前环境是否有可用的图片生成工具。

### 别人安装后能不能直接用？

可以。只要把 `skills/ecommerce-image-director` 放进 Codex skills 目录，就能作为 skill 调用。若要生成图片，还需要配置可用的图片生成模型或工具。

### 可以用于瓜子以外的品类吗？

可以。这个 skill 是品类通用的，会针对不同项目重新识别品类、平台、人群、包装、证明点和合规风险，不会固定在瓜子项目上。
