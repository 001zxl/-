# Reference Learning Playbook

Use this when the user asks for popular market design, competitor learning, fresh styles, or when generated images begin to look repetitive.

## Reference Pass

1. Search current examples by category + platform + image type.
   - Example: `sunflower seeds douyin ecommerce detail image`
   - Example: `snack product detail page design`
   - Example: `nuts ecommerce hero image packaging macro`

2. Collect patterns, not copies.
   Extract:
   - Product scale and crop.
   - Text hierarchy.
   - Background type.
   - Color rhythm.
   - Prop logic.
   - Trust module design.
   - Platform-specific hooks.

3. Map references to territories.
   Assign each useful reference to a style territory:
   - Clean trust.
   - Douyin viral sticker.
   - Macro proof.
   - Premium dark.
   - Editorial lifestyle.
   - Process/origin.
   - Variant shelf.

4. Build a style matrix before generation.
   For each output image specify:
   - Role.
   - Reference pattern borrowed.
   - New creative twist.
   - Product preservation plan.

5. Avoid imitation.
   Do not reproduce one competitor's exact composition, text, palette, or props. Borrow structural logic and adapt it to the user's product.

## Suggested Research Sources

- Official platform/store examples when available.
- Marketplace search results and category top sellers.
- Brand pages for similar product categories.
- Design/editorial references for layout rhythm.
- Product photography guides for lighting and packaging accuracy.

## Continuous Knowledge Update

When a generated result works well, append to `pattern-library.md`:

```text
Date:
Product/category:
Platform:
Style territory:
Reference pattern:
Prompt tactic:
What worked:

```

Keep updates short. The purpose is to build a practical pattern library, not a diary.
